# Галактическая Осада III — «Звёздный атлас»

Браузерная стратегия в духе Galcon (захват планет отправкой флотов), переосмысленная
относительно GS2: визуальный стиль старинного атласа неба, новое меню, новые механики, кампания.

**Live:** https://freejam.online/gs3/
**Код:** `/var/www/gs3` (статика, без сборки; отдаётся симлинком `/var/www/freejam/gs3`)
**История стилей:** акварельная и голографическая версии сохранены в `attic/`.

## Стиль «Звёздный атлас»
Лист старинной карты неба: пергамент с волокнами и разводами, гравюрная штриховка,
двойная латунная рамка с ромбами, розы ветров и навигационные круги, чернильные кораблики
с парусами и вымпелами. Планеты — гравированные медальоны владений (ляпис/киноварь/сепия/умбра),
числа гарнизонов — на пергаментных плашках IBM Plex Mono.
UI: Cormorant (заголовки) + Jost (текст) + Plex Mono, латунные кнопки-таблички,
анимированный переливающийся скроллбар (чернила → латунь → папоротник).

## Механики
- **Типы планет**: Терра, Газовый гигант (×1.55 производство, кольцо), Крепость (оборона ×2.2,
  бастионы), Верфь (+1 корабль/4.5 с своим планетам в радиусе 260), Астероид (мелкий, дешёвый).
- **Тёмная материя (✦) и 3 способности**: Орбитальный залп (3), Астральный щит (2),
  Звёздный мост (4). Клавиши 1/2/3 или кнопки, цель — кликом; мост — два клика по своим.
- **События**: кометы (заморозка планет на траектории), пираты (лагеря с рейдами, награда ✦),
  мятежи (планета уходит в нейтраль).
- **Кампания**: 9 систем в 3 главах с модификаторами, звёздная пыль, 4 мета-апгрейда,
  прогресс в localStorage (gs3_progress).
- Только одиночная игра: быстрая битва (3 сложности) + кампания.

## Управление
ЛКМ/тап по своей планете → выбор; протянуть к цели → отправка (есть автоприцел).
Колёсико / `[` `]` / чипы 25–100 % — доля отправки. Esc — отмена, P — пауза, R — заново.


## Проверено (реальный браузер, 2026-10-08)
Загрузка без ошибок консоли · drag-отправка флотов · все 3 способности через UI (залп 18→7,
щит активен, мост строится двумя кликами) · кометы/пираты/мятежи · победа/поражение ·
пыль и разблокировка систем (Сириус → звезда ★, связь сплошная, Вега пульсирует) ·
карта кампании и брифинг · пауза и финал с кнопками · мобильный 390×844 без наложений.
